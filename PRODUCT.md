## Platform

web

## Users

Người vận hành bộ Scripts Microsoft 365 E5 trên máy Windows cá nhân.

## Product Purpose

Theo dõi trạng thái mount, lịch chạy, nhật ký và khởi chạy các script hiện có từ Dashboard cục bộ.

## Capabilities and Constraints

Python phục vụ cổng 8765; PowerShell dự phòng cổng 5500. API status và run hiện có phải tiếp tục hoạt động. Không tạo dữ liệu trạng thái giả. Xác nhận trước tác vụ thay đổi dữ liệu hoặc lịch chạy.

## Brand Commitments

Người dùng chọn giao diện sáng, tiếng Việt đầy đủ, ưu tiên trạng thái hệ thống và nút thao tác thường dùng; điểm nhấn xanh lá.

dashboard/server.py, dashboard/E5-Dashboard.ps1 và README.md mô tả chức năng hiện có.
